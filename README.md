## 📋 نبذة عن المشروع

**AirRoom** هو تطبيق ويب حديث يتيح لك مشاركة الملفات بين جهازك والأجهزة الأخرى في الشبكة بسهولة فائقة. 

- ✨ **بدون تثبيت** — افتح الرابط من أي متصفح
- 🔐 **آمن وخاص** — جميع البيانات تُنقل مباشرة بين الأجهزة
- ⚡ **سريع جداً** — بدون تأخير أو انتظار
- 📱 **متجاوب تماماً** — يعمل على الهاتف والحاسوب والتابلت

---

## ✨ المميزات

### 🔄 مشاركة فورية
- انسخ رابط الاقتران وشاركه مع الشريك
- ارتباط آني بين الجهازين بمجرد الاتصال
- إخطار فوري عند انقطاع الاتصال

### 📁 نقل الملفات
- اسحب وأفلت الملفات مباشرة
- دعم الملفات الكبيرة جداً (حتى 100 ميجابايت للقطعة الواحدة)
- عرض تقدم النقل فوراً

### 🛡️ الأمان والخصوصية
- بدون حفظ في السحابة
- بدون سجلات أو بيانات وسيطة
- اتصال P2P مباشر عبر WebSockets

### 🎨 واجهة احترافية
- تصميم عصري وسهل الاستخدام
- دعم اللغة العربية بالكامل
- أيقونات وتنبيهات واضحة

## 🚀 البدء السريع

### المتطلبات
```bash
- Node.js >= 18.0.0
- npm أو yarn
```

### التثبيت المحلي

1. **استنسخ المستودع**
```bash
git clone https://github.com/Ayad-Mounir/airroom.git
cd airroom
```

2. **ثبّت المكتبات**
```bash
npm install
```

3. **شغّل الخادم**
```bash
npm start
```

4. **افتح في المتصفح**
```
http://localhost:3000
```

### التثبيت على Railway

المشروع جاهز للنشر على Railway:

1. اربط المستودع على Railway
2. سيعمل تلقائياً على `airroom-production.up.railway.app`
3. لا تحتاج لأي إعدادات إضافية

## 💡 الاستخدام

### الخطوة 1: افتح التطبيق
```
https://airroom-production.up.railway.app
```

### الخطوة 2: سمّ جهازك
أدخل اسماً سهل التذكر (مثل: "جهازي الشخصي")

### الخطوة 3: انسخ معرّف الاقتران
سيظهر معرّف فريد لجهازك — انسخه

### الخطوة 4: شارك مع الشريك
أرسل المعرّف للطرف الآخر عبر أي وسيلة

### الخطوة 5: استقبل الاتصال
- ألصق معرّف الشريك عندما يطلب التطبيق
- سيتم ربط الجهازين فوراً ✨

### الخطوة 6: انقل الملفات
- اسحب الملفات إلى منطقة الإفلات
- أو اضغط "اختر الملفات" لفتح المتصفح

## 🏗️ البنية التقنية

### الخادم (Backend)
```
- Express.js — خادم الويب
- Socket.io — الاتصال الثنائي الاتجاه
- Node.js native HTTP — خادم HTTP
```

### العميل (Frontend)
```
- Vanilla JavaScript (بدون frameworks)
- HTML5 APIs — Drag & Drop, File API
- WebSockets — اتصال P2P
- Service Workers — عمل بلا اتصال (قريباً)
```

### العمارة
```
[جهاز 1] ←→ [خادم Railway] ←→ [جهاز 2]
   (Client)       (Relay)        (Client)
```

## 🐛 حل المشاكل الشائعة

### ❌ لا يتصل الجهازان؟
- تأكد من أن كلا الجهازين متصلان بالإنترنت
- أعد تحميل الصفحة في كلا المتصفحين
- تأكد من نسخ المعرّف بشكل صحيح

### ❌ الملفات الكبيرة بطيئة جداً؟
- هذا طبيعي حسب سرعة الإنترنت
- يمكنك نقل ملفات متعددة في نفس الوقت
- جاري العمل على تحسين السرعة

### ❌ الخادم لا يستجيب؟
- افتح: https://railway.com/project
- تأكد من حالة الخدمة (Status)
- أعد النشر إذا لزم الأمر
